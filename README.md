# Sistema de Agendamento de Serviços

Projeto modular com Google Sheets e Google Apps Script.

## Estrutura
- Configurações, Clientes, Funcionários, Serviços, Agenda, Disponibilidade, Bloqueios e Status.
- Inicialização cria abas/cabeçalhos ausentes sem apagar dados existentes.
- Agenda unificada; seleção livre de funcionário e serviço.
- Duração automática, ajustes manuais previstos.

## Instalação
1. Abra uma planilha Google e Extensões > Apps Script.
2. Copie os arquivos da pasta apps-script.
3. Execute instalarSistema e autorize.

> Scaffold inicial: CRUD, interface e validação de conflitos ainda serão implementados.
